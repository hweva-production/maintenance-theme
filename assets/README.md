# Assets Folder

This folder contains:
- `favicon.svg` - Modern SVG favicon (included)
- `favicon.ico` - Traditional favicon (optional, create from SVG)
- `apple-touch-icon.png` - iOS home screen icon, 180x180px (optional)
- `og-image.jpg` - Social media preview image, 1200x630px (optional)

## Creating Additional Favicon Files

You can create `.ico` and `.png` files from the SVG using online tools like:
- https://realfavicongenerator.net/
- https://favicon.io/

Just upload the `favicon.svg` file and generate the required formats.
